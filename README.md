# 📱 AttendX

> Smart Attendance & Productivity Tracking App 🚀

AttendX is an Android application designed to simplify and modernize attendance tracking. It provides a seamless way to manage, monitor, and analyze attendance with an intuitive UI and efficient backend integration.

---

## ✨ Features

- 📊 Real-time Attendance Tracking
- 🔐 User Authentication (Firebase)
- 📷 Barcode / QR Scanner Integration
- 📁 Cloud Data Storage (Firebase Firestore)
- 📈 Attendance Analytics & Insights
- 🌐 API Integration (Retrofit)
- 🎯 Clean and Simple UI (XML-based)

---

## 🛠️ Tech Stack

- Language: Kotlin  
- UI: XML (Android Views)  
- Backend: Firebase (Authentication + Firestore)  
- Networking: Retrofit
